# Nguyen Ngoc Toan — Portfolio CV

Single-file static site (`index.html`). No build step.

## Deploy to GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name, e.g. `cv`).
2. Upload `index.html`, `.nojekyll` and this README to the repo root.
3. Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
4. Site is live at `https://<your-username>.github.io/` (or `/cv/`) after ~1 minute.

Edit content directly in `index.html`. Skill levels live in the `SKILLS` array near the bottom.
