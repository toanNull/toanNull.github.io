// about

From shop floor to system design

I started on a footwear production floor learning how a work order really moves through a plant. Since 2022 I have worked at Fujikura Fiber Optics Vietnam alongside a Japanese engineering team, taking over and extending the software that runs optical-fiber production lines.

Today I am the primary architect of FOV PMS, a PLC-and-vision inspection platform, and I lead a small development team. I care about software that is easy for operators, safe to extend, and boring in production: lazy hardware initialisation, per-camera locks, clean SQL cursor lifecycles, and judgment logic that a quality engineer can audit.

I work across the stack: WPF and WinForms on the line, Blazor Server and ASP.NET Core for the web, Python for computer vision, and SQL Server underneath it all.

FOV PMS — PLC & Vision Manufacturing System

An inspection platform that reads labels and markings on optical-fiber components, decides Good / No-Good and logs every result for traceability.

  • PLC-triggered dual-camera capture with per-camera locks to prevent trigger cross-talk.
